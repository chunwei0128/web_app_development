# PRD - 線上算命系統

## 1. 專案概述
- **背景與動機**：現代人生活節奏快、壓力大，面對感情、事業、健康等抉擇時常會感到迷惘。然而，親自前往實體廟宇或算命館往往受限於時間與空間距離。因此，本專案期望打造一個「線上算命系統」，讓使用者能透過網路隨時隨地獲得心靈指引，同時保留傳統宗教文化中的儀式感與回饋機制。
- **目標用戶**：
  - 對未來發展（事業、感情等）感到迷惘、需要指引的年輕人與上班族。
  - 有傳統宗教信仰，但因工作繁忙無法經常抽空前往實體廟宇的信眾。
  - 平時喜歡透過星座、塔羅、求籤等方式尋求心靈慰藉的大眾。
- **核心價值主張**：打破時空限制，提供即時、方便且具儀式感的心靈指引服務；結合傳統宗教文化，透過數位化的方式延續「求籤、解惑、添香油錢」的信仰互動。

## 2. 功能需求
以下列出本系統的主要功能與對應的使用者故事：

### 主要功能清單
1. **算命、占卜、線上抽籤**（包含模擬擲筊、抽籤詩流程）
2. **詳細解籤與結果顯示**（提供白話文解析與吉凶說明）
3. **儲存抽籤結果與歷史紀錄**（讓使用者能夠回顧過去的指引）
4. **線上捐贈香油錢**（虛擬點數或模擬/真實金流串接）
5. **會員註冊與登入系統**（用於管理個人紀錄與成就）

### 使用者故事 (User Stories)
- 作為 **使用者**，我希望 **能夠進行線上求籤與擲筊**，以便 **在遇到困惑時隨時獲得神明的指引**。
- 作為 **使用者**，我希望 **能看到籤詩的詳細白話解說**，以便 **清楚理解籤詩背後的具體涵義與建議**。
- 作為 **註冊會員**，我希望 **能夠將抽籤結果儲存到我的個人帳戶中**，以便 **未來可以隨時回顧並驗證過去的指引**。
- 作為 **信眾**，我希望 **能夠有線上捐獻香油錢的功能**，以便 **在覺得準確或靈驗時能夠還願並表達感謝**。
- 作為 **使用者**，我希望 **能註冊並建立個人帳號**，以便 **系統能記住我的資訊、歷史紀錄以及捐獻名錄**。

## 3. 非功能需求
- **技術限制**：
  - 後端：使用 Python 的 **Flask** 框架。
  - 前端渲染：使用 **Jinja2** 模板引擎搭配純 CSS/JS，或視需要引入 Bootstrap/Tailwind 等輕量工具。
  - 資料庫：使用 **SQLite** 進行資料儲存，以符合輕量化與快速開發的需求。
- **效能與安全考量**：
  - 密碼安全：使用者登入密碼必須經過單向加密（例如 bcrypt）後再存入資料庫。
  - 防護機制：表單送出需防禦 CSRF 及 SQL Injection 等常見網路攻擊。
  - 回應效能：抽籤與擲筊的運算需在極短時間（< 1秒）內完成，提供流暢的即時反饋感。
  - 使用者體驗 (RWD)：系統介面必須具備響應式設計，確保在手機、平板與桌機上均能順暢操作。

## 4. MVP 範圍 (Minimum Viable Product)
- **Must Have (核心必要功能)**：
  - 基本的會員註冊與登入功能。
  - 線上抽籤功能流程（單次抽籤、顯示對應的籤詩畫面）。
  - 靜態的籤詩資料庫（例如 60 首或 100 首觀音靈籤），包含籤詩原文與基本解籤。
  - 模擬捐贈香油錢的介面與表單（填寫金額與祈福語）。
- **Should Have (重要功能)**：
  - 完整的儀式感互動（例如：點擊按鈕模擬「擲筊」確認是否為此籤）。
  - 儲存並列出使用者的歷史抽籤紀錄。
  - 記錄使用者的「香油錢」捐獻歷史與排行榜。
- **Nice to Have (加分功能/未來擴充)**：
  - 籤詩圖片產生器，方便使用者分享至 Facebook/Instagram/Line 等社群媒體。
  - 每日運勢推播或訂閱功能。
  - 實際串接第三方支付 API（如 Line Pay / 綠界）進行真實香油錢捐贈。
